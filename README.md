# CityCareAI
CityCare – AI-Powered City Problem Intelligence Platform is a web-based civic complaint management system designed to make the reporting and monitoring of urban problems more organised and transparent. Citizens often experience issues such as damaged roads, water-supply interruptions, electricity faults, overflowing garbage and poor public infrastructure. When complaints are received through disconnected channels, it becomes difficult for authorities to classify them, identify urgent cases and recognise locations where problems are repeatedly reported.
CityCare provides a centralised online portal through which citizens can submit civic complaints along with their name, description, location and an optional image. The application stores complaint records in a MySQL database and uses a Machine Learning model to predict the complaint category from its text. The system then applies rule-based logic to estimate severity and assign a priority level. A predefined department mapping is used to route each category to the relevant department.
